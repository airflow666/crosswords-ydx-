# 🧩 Кроссворды (Crosswords)

Казуальная HTML5-игра по разгадыванию **классических кроссвордов** для платформы
[Яндекс Игры](https://yandex.ru/games). Написана на ванильном JS + Vite, без
игровых движков.

**Главная фишка:** каждый кроссворд **генерируется автоматически и уникален** —
двух одинаковых сеток у разных игроков (и у одного игрока в разных партиях) не
бывает. Генерация сеедируемая, поэтому незаконченную партию можно продолжить
после перезагрузки — сетка воспроизводится точно.

Аудитория — люди, которые хотят спокойно разгадывать кроссворды. Отсюда: без
соревновательности, без внутриигровой валюты, без навязчивой рекламы.

## Возможности

- **Уникальный плотный кроссворд** в каждой партии: сетка строится по шаблону и заполняется словами backtracking-ом (пересекающиеся слова, а не «полоски»); сеедировано — тот же seed даёт ту же сетку, разные seed'ы — разные
- **Три уровня сложности** (лёгкий 7×7, средний 9×9, сложный 11×11) — выбор в меню
- **Игра только на русском** — встроенный русский словарь (~1000 слов) в сборке
- **Постоянная палитра из 8 букв** снизу — тап вместо мелкой клавиатуры (правильная буква + 7 правдоподобных отвлекающих); панель не прыгает, доска не дёргается. На десктопе — ещё и ввод с физической клавиатуры
- **Адаптивный дизайн** — крупные клетки-плитки в стиле логотипа; на телефоне одна колонка, на десктопе — сетка + список определений сбоку
- **До 3 подсказок за партию** — подсказка открывает несколько случайных букв, выдаётся за rewarded-ролик
- **Аккуратная реклама** — rewarded за подсказку + interstitial в естественных паузах (после победы и при отказе от партии ради новой); на старте игры из меню и во время решения рекламы нет. Баннеров нет
- **Личная статистика** вместо лидербордов: разгадано кроссвордов, серия дней, лучшее/среднее время
- **Светлая и тёмная темы** (авто по системе + переключатель)
- **Облачные сохранения** (`player.setData`) с fallback на localStorage; прогресс переживает перезагрузку
- **Звук** синтезируется на WebAudio — внешних ассетов в сборке нет
- **Mock-режим SDK**: вне Яндекса игра полностью играбельна, реклама эмулируется (лог `[YSDK-mock]`)

## Разработка

```bash
npm install
npm run dev      # http://localhost:5173 — mock-режим SDK
npm run build    # продакшн-сборка в dist/
npm test         # юнит-тесты генератора (детерминизм, уникальность, корректность сеток)
```

## Публикация в Яндекс Играх

1. **Сборка и архив** (Linux/macOS)

   ```bash
   npm run build
   cd dist && zip -r ../crosswords.zip . && cd ..
   ```

   Важно: `index.html` должен лежать в корне архива (так и получается при команде выше).

   **На Windows** (PowerShell): установите [Node.js LTS](https://nodejs.org/), затем

   ```powershell
   npm install
   npm run build
   Compress-Archive -Path dist\* -DestinationPath crosswords.zip -Force
   ```

   ⚠️ Именно `dist\*` (содержимое папки), а не `dist` — иначе `index.html` окажется
   внутри вложенной папки, и Яндекс такую сборку не примет.

2. **Консоль разработчика**: на [games.yandex.ru/console](https://games.yandex.ru/console/)
   создайте черновик и загрузите `crosswords.zip`. Материалы для карточки —
   в [`store/CARD.md`](store/CARD.md).

3. **Реклама**: монетизация включается в консоли (раздел «Реклама»). В игре
   используются rewarded-видео (за подсказку) и interstitial в естественных
   паузах (после победы и при отказе от партии ради новой, с кулдауном ~60 сек);
   на старте игры рекламы нет. Отдельных ad unit id в коде не нужно — SDK сам
   решает, что показать.

4. **Песочница**: черновик доступен по ссылке вида
   `https://yandex.ru/games/app/<ID>/?draft=true` — там работает настоящий SDK
   (реклама, облачные сохранения). Индикатор загрузчика в
   [debug-панели](https://yandex.ru/dev/games/doc/ru/console/debug-panel):
   `W` — SDK ещё не готов, `IT` — всё в порядке.

   Особенности сборки, снимающие типичные проблемы хостинга Яндекса (уже учтены
   в `vite.config.js`):
   - JS/CSS кладутся **в корень** `dist/`, без подпапки `assets/` (файлы из
     подпапки стабильно 404-ились на хостинге Яндекса);
   - со скрипта снимается атрибут `crossorigin` (иначе раздача с CDN-поддомена
     без CORS молча блокирует модуль);
   - `/sdk.js` подключается программно из `src/yandex/sdk.js`, а не тегом в
     `index.html` — устойчивее к строгому CSP и без гонки состояний.

## Чек-лист модерации (учтено в коде)

- `LoadingAPI.ready()` — ровно один раз после загрузки (в меню)
- `GameplayAPI.start()/stop()` — на старте/паузе геймплея, стоп на рекламе и при сворачивании вкладки
- **Нет запросов к внешним доменам** — словарь, шрифты (системные) и звук в сборке; проверено smoke-тестом
- Награда за rewarded (открытие букв) — только после события `onRewarded`
- Не требует авторизации/персональных данных (`getPlayer({ scopes: false })`), fallback на localStorage
- Русская локализация; звук глушится на рекламе и при сворачивании; кнопка звука в меню и в игре
- Все вызовы SDK в try/catch — отказ рекламы/сохранений не ломает игру
- Прогресс переживает перезагрузку (сохранение партии с flush)

## Как это генерируется

`generatePuzzle(seed, level)` работает в два этапа:

1. **Шаблон** (`makeTemplate`) — по seed строится плотный узор чёрных клеток:
   белую сетку «дырявим» так, чтобы не было огрызков (пробегов длины 2), каждая
   белая клетка входила хотя бы в одно слово ≥3, а область оставалась связной.
   Получается компактная доска из пересекающихся слов, а не «полоски».
2. **Заполнение** (`fill`) — backtracking по эвристике MRV (сначала слот с
   наименьшим числом кандидатов; быстрый подсчёт кандидатов через индекс
   `wordbank.js`). Слова из словаря подставляются так, чтобы все пересечения
   совпадали. Бюджет шагов вместо таймеров — результат не зависит от скорости
   машины (детерминизм).

Один seed всегда даёт одну и ту же сетку (для возобновления партии), разные seed —
разные (уникальность). Если удачно уложить не вышло за отведённые попытки, берётся
самая заполненная валидная сетка того же уровня — генерация не «падает».

> Плотность сеток (~0.6 занятых клеток) ограничена размером встроенного словаря:
> чем больше слов, тем плотнее можно паковать. Словарь легко расширяется —
> формат `{ a: 'СЛОВО', c: 'определение' }` в `src/game/dictionary.ru.js`.

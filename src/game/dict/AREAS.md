# Подобласти тематических словарей

Рабочий список для наполнения паков `theme.*.js`. Слов здесь нет намеренно —
это карта того, что ещё предстоит покрыть.

## Зачем этот файл

Первые проходы по темам шли свободным подбором: «что вспомнилось про космос».
Так набирается первая пара сотен слов, а дальше отдача обрушивается — на третьем
круге кухня приняла 10 новых слов из 171 предложенного, космос 14 из 176.
Предлагается почти исключительно то, что уже написано, и время уходит на
проверку повторов.

Обход по подобластям снимает это: внутри «приправ» или «крепежа» видно, что
именно ещё не названо, и подбор перестаёт ходить по кругу.

## Как пользоваться

Один проход — одна подобласть. Отмечаем `[x]`, когда область выбрана досуха
(придумывается только то, что уже есть в паке).

```bash
# слова пишутся в текстовый файл по строке «СЛОВО|определение»
node test/format-dict.mjs --max=7 src/game/dict/theme.<тема>.js
npm run lint:dict
```

**Требования к словам** (проверяются линтером):
нарицательное существительное в именительном падеже единственного числа;
3–7 букв (длиннее в тематическую сетку не помещается); только кириллица;
ответ не просвечивает в собственном определении; одно определение — одно слово;
без имён собственных; без запрещённого §3.4 площадки.

**Ориентир по объёму.** Цель — 600–800 слов на тему.

## Чем третий проход отличался от первых двух

Первые два шли по памяти: берём подобласть и вспоминаем, что в неё попадает.
Способ работает, пока область не вычерпана, и упирается ровно в тот потолок,
ради которого заведён этот файл.

Третий проход шёл **от источника** — от `dictionary.ru.js`, прежнего словаря
игры на 4600 слов, уже прошедшего модерацию. `test/mine-dict.mjs` вычитает из
него всё, что уже разложено по темам, и печатает остаток. Вопрос меняется с
«что я могу вспомнить про кухню» на «что в словаре лежит без темы», а это
принципиально другой вопрос — и отдача у него выше.

На старте прохода в остатке было 1310 слов, разобрано около 460. Осталось 831 —
это отвлечённая лексика (чувства, отношения, свойства), которой в тематических
паках и не место: она честно принадлежит лёгкому режиму.

Повторов при слиянии за весь третий проход — ноль. Ловились только
самопросвечивающие определения вроде «ЗВОНОК — прибор, что подаёт сигнал
звоном»: когда слово берётся из готового списка, а не придумывается, соблазн
описать его однокоренным словом заметно выше. Линтер их снимает.

## Как вести следующий проход

```bash
node test/mine-dict.mjs > /tmp/rest.txt   # что ещё лежит в источнике без темы
```

Прежние определения из источника печатаются как подсказка о значении, но
переносить их дословно не надо: одно и то же слово в «Природе» и в «Кухне»
определяется с разных сторон.

Когда источник исчерпан, следующий шаг — внешний: определитель растений,
каталог инструментов, поварская книга. Паки уже в целевом диапазоне, так что
это работа на качество и разнообразие, а не на объём.

Галочки ниже по-прежнему не проставлены: `[x]` означает «выбрано досуха», а
три прохода такого утверждения не дают.

# Гайд по заполнению черновика в консоли Яндекс Игр

Пошаговое описание **всех полей черновика** в [консоли разработчика](https://games.yandex.ru/console/)
с готовыми значениями для копирования. Основано на официальной документации
([Загрузка игры](https://yandex.ru/dev/games/doc/ru/console/add-new-game),
[Требования к игре](https://yandex.ru/dev/games/doc/ru/concepts/requirements)) —
сверено на момент подготовки; сама консоль всегда показывает актуальные лимиты
инлайн (счётчики символов, подсказки под полями), ориентируйтесь на них, если
что-то разойдётся с этим файлом.

Готовые изображения — в [`store/assets/`](assets/) и [`store/screenshots/`](screenshots/)
этого репозитория (см. раздел 4).

---

## 1. Сборка и архив

Обязательное поле: **Archive** (загрузка zip).

| Требование | Как в проекте |
|---|---|
| `index.html` строго в корне архива | ✅ `vite.config.js` (`assetsDir: ''`) кладёт всё в корень `dist/` |
| Имена файлов/папок без пробелов и кириллицы | ✅ хэшированные англ. имена бандлов |
| Все файлы игры (распакованные) ≤ 100 МБ | ✅ вся сборка ~195 КБ (JS ~176 КБ + CSS ~15 КБ + HTML ~2 КБ) |
| Рекомендуемый вес первой загрузки ≤ 10 МБ | ✅ с большим запасом |
| Пути относительные (площадка раздаёт игру из подкаталога) | ✅ `base: './'` |

Команда сборки и архивации — см. [`README.md`](../README.md#публикация-в-яндекс-играх).

## 2. Обязательные текстовые поля

Из документации: обязательны **Title, About the game, How to play, Version,
Categories, Icon, Cover, Archive, Supported platforms, Orientation**. Ниже —
готовые значения; те же тексты лежат в [`CARD.md`](CARD.md). Игра русскоязычная,
англоязычных версий текстов нет и не планируется (см. раздел 6).

| Поле в консоли | Значение (RU) |
|---|---|
| **Title / Название** | Кроссворды |
| **Short description / Краткое описание** | Классические кроссворды, которые генерируются заново при каждой партии. Спокойно, без спешки и навязчивой рекламы. |
| **About the game / Описание игры** | См. «Полное описание» в [`CARD.md`](CARD.md#полное-описание) — вступление + список возможностей. |
| **How to play / Как играть** | Нажмите «Играть» — сложность выбирается случайно. Тапните клетку в сетке: внизу, прямо над буквами, появится определение к выбранному слову и счётчик отгаданных, а под ним — палитра на всё слово (буквы самого слова вперемешку с несколькими лишними). Стрелки листают только неотгаданные слова; когда слово сходится, игра сама переходит к следующему. Если слово вписано целиком, но неверно, об этом сказано в строке определения. Кнопка «Подсказка» открывает буквы в текущем слове: первая за партию бесплатно, дальше — за просмотр рекламы, всего 5. Открытые и уже отгаданные буквы менять нельзя. |
| **Version / Версия** | 1.3.0 (см. `package.json` — держите поле в консоли синхронным с ним) |

> Правило площадки: название игры должно **дословно совпадать** на всех
> материалах — в самой игре, в архиве, на иконке/обложке/скриншотах (если там
> есть текст с названием). У нас оно написано текстом **на обложке**
> (`store/assets/cover-800x470.png` — «КРОССВОРДЫ»), а также стоит в `<title>`
> страницы и на экране меню внутри игры. Везде это одно и то же слово —
> «Кроссворды». Поэтому в поле Title вводите ровно `Кроссворды`, без приписок:
> любое уточнение вроде «— уникальные каждый раз» разойдётся с обложкой.
> Подзаголовок с обложки («Новый кроссворд каждый раз») — не часть названия,
> это слоган, он совпадает с подзаголовком на экране меню.

Игра **только на русском** — заполняйте все текстовые поля по-русски и укажите
единственный язык «русский» (см. раздел 6).

## 3. Категория, теги, возрастной рейтинг, платформы

| Поле | Рекомендуемое значение | Комментарий |
|---|---|---|
| **Category / Категория** | **Головоломки** (Puzzle) | Иногда категория для словесных игр также помечается как «Настольные» — выбирайте, что ближе всего в актуальном выпадающем списке консоли на момент загрузки, список категорий периодически меняется. |
| **Age rating / Возрастной рейтинг** | **0+** | Площадка требует выбрать одну из пяти возрастных категорий (0+/6+/12+/16+/18+); в игре нет насилия, покупок за реальные деньги и сбора персональных данных — 0+ обоснован. |
| **Supported platforms / Платформы** | **Мобильные + Десктоп** (оба) | Игра адаптивна: проверено на телефоне (портрет и альбом), планшете и десктопе — см. скриншоты в разделе 4. |
| **Orientation / Ориентация** | **Любая / обе** (portrait + landscape) | Игра не блокирует ориентацию и корректно работает в обеих (см. `09-game-landscape-light.png`); если консоль просит выбрать одну основную — ставьте **портретную** как приоритетную для мобильных. |

## 4. Медиаматериалы

### Иконка (обязательно)

| Требование | Значение |
|---|---|
| Размер | 512 × 512 px |
| Формат | PNG, 32-бит |
| Вес | ≤ 1024 КБ |
| Форма | строго квадратная, **без** скруглённых углов (скругление накладывает сама площадка) |
| Файл в проекте | [`store/assets/icon-512.png`](assets/icon-512.png) — 512×512, ~15 КБ |
| Как сделана | скриптом [`store/make-assets.mjs`](make-assets.mjs): та же эмблема, что на обложке и на экране меню (белая карточка, бирюзовые плитки), на бирюзовом фоне для заметности в витрине |

### Обложка (обязательно)

| Требование | Значение |
|---|---|
| Размер | 800 × 470 px |
| Формат | PNG |
| Файл в проекте | [`store/assets/cover-800x470.png`](assets/cover-800x470.png) — 800×470, ~24 КБ |
| Как сделана | тем же скриптом `make-assets.mjs` — эмблема **идентична** иконке, рядом название и слоган, дословно совпадающие с экраном меню |

### Скриншоты (обычно 3–5 шт.)

| Требование | Значение |
|---|---|
| Формат | PNG или JPEG, 24-бит, **без альфа-канала** |
| Соотношение сторон | строго **16:9** для альбомной ориентации и **9:16** для портретной |
| Размер | **длинная сторона от 1280 до 2560 px** |
| Не использовать как иконку/обложку | верно — это отдельные файлы |
| Без чёрных полос/рамок вокруг игры | ✅ скриншоты — чистая область интерфейса |

> Консоль проверяет и пропорции, и длинную сторону. Скриншот 540×960 формально
> имеет верные 9:16, но по длинной стороне (960) не дотягивает до 1280 и будет
> отклонён — на этом набор уже спотыкался. Поэтому нужное разрешение набирается
> масштабом устройства, а не растягиванием вёрстки: макет рендерится при
> телефонной ширине в CSS-пикселях, иначе телефонный интерфейс превратился бы
> в планшетный.

Набор генерируется скриптом [`store/make-screenshots.mjs`](make-screenshots.mjs)
(команда — в [`README.md`](../README.md#медиаматериалы-для-карточки)), поэтому
пропорции и состав воспроизводимы и не разъезжаются между итерациями.

**Пропорции и размеры выдержаны точно:** портретные мобильные — **1080×1920**
(ровно 9:16), альбомная ориентация и десктоп — **1920×1080** (ровно 16:9).
Длинная сторона везде 1920, то есть внутри требуемых 1280–2560. PNG без
альфа-канала. Скрипт проверяет это сам и падает с ошибкой, если размер вышел
за рамки, — молча выпустить неподходящий файл уже не получится.

Каждый экран снят **в светлой и в тёмной теме**:

| Файл | Размер | Что показывает |
|---|---|---|
| `01-menu-mobile-light.png` / `02-…-dark.png` | 1080×1920 | Главное меню, телефон |
| `03-game-mobile-light.png` / `04-…-dark.png` | 1080×1920 | Игра: определение и буквы единым блоком внизу, счётчик слов, готовые буквы отдельным стилем |
| `05-results-mobile-light.png` / `06-…-dark.png` | 1080×1920 | Экран победы с коротким салютом |
| `07-stats-mobile-light.png` / `08-…-dark.png` | 1080×1920 | Личная статистика (с накопленными данными, без времени) |
| `09-game-landscape-light.png` / `10-…-dark.png` | 1920×1080 | Игра в альбомной ориентации на телефоне (компактный режим) |
| `11-menu-desktop-light.png` / `12-…-dark.png` | 1920×1080 | Меню на широком экране |
| `13-game-desktop-light.png` / `14-…-dark.png` | 1920×1080 | Игра на десктопе: сетка + список определений сбоку, отгаданные зачёркнуты |
| `15-results-desktop-light.png` / `16-…-dark.png` | 1920×1080 | Экран победы на десктопе |
| `17-stats-desktop-light.png` / `18-…-dark.png` | 1920×1080 | Статистика на десктопе |

**Рекомендация для слота «5 скриншотов» в консоли**: `03`, `13`, `05`, `04`, `09` —
мобильная игра, десктопная игра, экран победы, тёмная тема и альбомная
ориентация одним набором. Если консоль разрешает больше — добавьте остальные.

### Видео (опционально)

Не готовили — необязательное поле. Если нужно, можно записать экран во время
`npm run dev` (mock-режим SDK, полностью играбельно).

## 5. Монетизация / реклама

Отдельных ad unit id вводить не нужно — Яндекс SDK сам решает, что показывать.
В консоли включите раздел **«Реклама»**. В самой игре используются:

- **Rewarded-видео** — за подсказку, по инициативе игрока. Подсказок за партию
  пять, **первая бесплатная** (ролик не показывается вообще), за остальные —
  rewarded. Награда (открытые буквы) начисляется только по событию
  `onRewarded`: если игрок закрыл ролик раньше, ничего не открывается.
- **Interstitial** — после победы («Новый кроссворд») и когда игрок бросает
  незаконченную партию ради новой; кулдаун ~60 сек. **На старте игры из меню и
  во время решения рекламы нет.**
- Баннеров нет.

## 6. Локализация

- Игра **только на русском** (интерфейс и словарь кроссвордов). Английскую
  версию делать не планируем.
- В консоли в поле **Languages / Языки** укажите **только русский**.
- Все текстовые поля карточки заполняйте по-русски.

## 7. Лидерборды

**Не используются намеренно** — продуктовое решение: ЦА игры (спокойное решение
кроссвордов) не нуждается в соревновательности. Раздел «Лидерборды» в консоли
можно пропустить.

## 8. Облачные сохранения

Ничего дополнительно настраивать не нужно — игра использует
`player.setData`/`getData` через SDK (см. `src/systems/saves.js`), доступный
всем играм по умолчанию.

## 9. Чек-лист перед отправкой на модерацию

Из общих требований и уже учтённого в коде (подробнее — в
[`README.md`](../README.md#чек-лист-модерации-учтено-в-коде)):

- [ ] Собрать (`npm run build`) и заново заархивировать (`dist/*` → zip)
- [ ] Заполнить все обязательные поля из разделов 2–3
- [ ] Загрузить иконку и обложку из `store/assets/`
- [ ] Загрузить 3–5 скриншотов из `store/screenshots/`
- [ ] Включить рекламу в разделе «Реклама»
- [ ] Проверить черновик в песочнице (`?draft=true`) — реальный SDK: реклама,
      облачные сохранения, индикатор `IT` в debug-панели
- [ ] Убедиться, что название игры одинаково всюду (заголовок, архив, медиа)
